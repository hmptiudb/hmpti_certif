# Kontribusi

1. Fork / buat branch dari `main` (`feat/nama-fitur`, `fix/nama-bug`).
2. Jalankan `php artisan test` dan `./vendor/bin/pint` sebelum commit.
3. Gunakan pesan commit singkat dan jelas, buka Pull Request ke `main`.
4. Jangan commit `.env`, kredensial, atau file service account Google.
